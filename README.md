## Sobre o projeto

Página de estudos desenvolvida com acompanhamento das aulas e lives do **Dev em Dobro**. O projeto explora a construção de uma interface visual, navegação entre conteúdos e interações no navegador usando **HTML, CSS e JavaScript**.

## Funcionalidades

- Seleção de **nove personagens** da tripulação por botões ilustrados.
- Atualização da imagem, nome e descrição do personagem selecionado.
- Destaque visual para o botão e o personagem ativos.
- Adaptações de layout para dispositivos móveis, com navegação horizontal pelos ícones.

## Como funciona

A aplicação associa cada botão ao personagem correspondente. Ao clicar, o JavaScript alterna a classe CSS `selecionado`, exibindo apenas o conteúdo escolhido. O projeto não depende de API nem de backend.

## Executar localmente

Clone ou baixe o repositório e abra `index.html` em um navegador moderno.

## Estrutura

~~~text
index.html          personagens, informações e navegação
src/css/            estilos, reset e regras responsivas
src/js/index.js     lógica de seleção
src/images/         artes, fundos e ícones dos personagens
~~~
